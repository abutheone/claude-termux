# zsh completion and the `claude` shortcut

The one-line installer places the launcher at `~/.local/bin/claude-termux`. For a
manual build, replace that path below with the built `target/release/claude-termux` file.

## Turn on zsh completion

Run this once in zsh:

```sh
echo 'source <("$HOME/.local/bin/claude-termux" completions zsh)' >> "$HOME/.zshrc"
```

Restart Termux or reload the setting with `source ~/.zshrc`. Type part of a
command or option and press Tab. Completion is generated by the installed launcher
each time zsh starts, so it stays in step with that launcher's own commands and
options. File and directory arguments use zsh's normal path completion.

## Add a short `claude` command

To start Claude with `claude`, add this function to `~/.zshrc`:

```sh
claude() {
    "$HOME/.local/bin/claude-termux" run -- "$@"
}
```

This leaves any existing `claude` executable on disk. In the current shell, remove
the function with `unfunction claude`. Remove the saved function from `~/.zshrc`
to stop loading it in new shells.

## Bash

Generate completion code with:

```sh
~/.local/bin/claude-termux completions bash
```

Use the command's output with your Bash completion setup. The one-line setup above
is for zsh.

## Extra network hosts

For example, to allow npm registry downloads during one Claude session:

```sh
~/.local/bin/claude-termux run --allow-host registry.npmjs.org
```

Only the host named in this command is added. Other hosts may be needed for a tool.
